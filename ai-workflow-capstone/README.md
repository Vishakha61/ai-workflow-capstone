# Country-Level Business Prediction (AI Workflow Capstone)

A reproducible demo project for a business prediction workflow: data ingestion, exploratory data analysis (EDA), comparison against a baseline, model training, a FastAPI prediction service, logging, tests, and Docker.

> **Important:** `data/country_business_data.csv` is a small illustrative dataset created for this repository scaffold. It is not an official economic dataset and the scores are synthetic. Replace it with the dataset from your Coursera lab before claiming this is your completed capstone.

## 1. Run locally

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python scripts/ingest_data.py
python scripts/run_eda.py
python scripts/train_model.py
uvicorn app.api:app --host 0.0.0.0 --port 8000
```

Open `http://127.0.0.1:8000/docs` for interactive API documentation.

## 2. API examples

Predict for one country:

```bash
curl "http://127.0.0.1:8000/predict?country=India"
```

Predict for all countries and get a combined average:

```bash
curl "http://127.0.0.1:8000/predict/all"
```

Health and basic performance information:

```bash
curl "http://127.0.0.1:8000/health"
curl "http://127.0.0.1:8000/metrics"
```

`/metrics` reports request count, average latency, and maximum latency for this process. It is a lightweight demonstration, not a full production monitoring system.

## 3. Tests

Run all tests with one command:

```bash
pytest -q
```

or:

```bash
bash run_tests.sh
```

On Windows without Bash, run `pytest -q` directly. Tests use temporary model/data files and a temporary log destination where appropriate; they do not write to production logs or overwrite the trained model.

## 4. Docker

Build and start:

```bash
docker compose up --build
```

Then open `http://localhost:8000/docs`.

## 5. Model comparison and EDA

`python scripts/train_model.py` compares a `DummyRegressor` baseline, `LinearRegression`, and `RandomForestRegressor`. It saves metrics to `artifacts/model_metrics.json` and the selected model to `artifacts/model.joblib`.

`python scripts/run_eda.py` writes charts to `artifacts/eda_target_distribution.png` and `artifacts/eda_correlation.png`. Training also saves `artifacts/model_vs_baseline.png`.

## 6. Data and limitations

The demo target is `business_index`, an illustrative numeric business outcome. Features are population, GDP per capita, internet penetration, inflation, and unemployment. The data is deliberately small so the project can run without external downloads. Metrics from this toy dataset are not suitable for business decisions. For the actual peer review, use the exact dataset and target defined by your Coursera assignment, document the source, and rerun the full workflow.
